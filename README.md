# Customer Churn & Predictive Analytics

Project 4 of a five-project analytics portfolio. This project will combine customer-retention analysis, SQL, statistical testing, leakage-safe predictive modelling, explainability, intervention economics, an interactive Streamlit dashboard, and automated tests.

## Business objective

Identify which customer groups are most likely to churn, quantify the commercial drivers associated with churn, and build a carefully evaluated model that helps prioritize retention outreach without presenting predictions as certainty.

## Initial data source

IBM's synthetic Telco Customer Churn sample contains 7,043 fictional customer records with service, contract, tenure, billing, payment, and churn fields. See `data/SOURCES.md` for source attribution and limitations.

## Planned workflow

1. Reproducible acquisition and schema validation.
2. Exploratory retention and revenue-risk analysis.
3. SQL segmentation and cohort analysis.
4. Statistical tests with effect sizes.
5. Leakage-safe classification with chronological limitations documented.
6. Threshold selection based on retention costs and expected value.
7. Model interpretation and subgroup performance checks.
8. Interactive dashboard, automated tests, GitHub publication, and Streamlit deployment.

> The dataset is synthetic and cross-sectional. Results are educational and must not be treated as evidence about real customers or used for consequential automated decisions.
